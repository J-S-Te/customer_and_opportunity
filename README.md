## 二、如何运行

- 三个子系统均为**单文件 HTML**，浏览器双击或 `file://` 打开即可运行，**无需服务器、构建或外部依赖**。
- 门户端会在线拉取 Google Fonts 字体，离线时仅字体回退，不影响布局与交互。
- 管理端含内置演示登录页（任意账号/密码可进入）；页面底部带「演示角色」切换器，用于演示 **Q4 权限收敛**。

## 三、管理端原型（含售前技术支持）

**文件**：`客户与商机管理子系统-管理端（含售前技术支持）.html`

**面向对象**：销售、销售总监、团队负责人、实施工程师、技术负责人（底部可切换演示角色）

**页面结构**：

| 区域 | 页面 | 内容要点 |
|---|---|---|
| 宿主（CRM） | 客户管理 | 客户列表（演示 8 家），新建/查看 |
| 宿主（CRM） | 商机管理 | 商机看板/列表（演示 12 条），阶段推进 |
| 宿主（CRM） | 客户详情 | 客户档案、关联商机 |
| 宿主（CRM） | 商机详情 | **已增强**：新增「售前技术支持」关联区 + 右上角「发起售前支持」入口（P-06） |
| 售前技术支持（内嵌） | 售前任务（TS-01） | 列表/看板，按角色收敛视图（Q4） |
| 售前技术支持（内嵌） | 新建售前申请（TS-02） | 场地类型（现场/远程，现场必填地址）+ 联系人/联系电话 |
| 售前技术支持（内嵌） | 售前任务详情（TS-03） | 流程时间线 + 两级审批 + 指派 + 执行进度 + 实施对接信息卡 |
| 售前技术支持（内嵌） | 工时登记（TS-04） | 小时自动换算人天（呼应 Q5）+ 数据流 K 推送状态反馈 |
| 售前技术支持（内嵌） | 技术人员池（TS-05） | 来自数据流 J 同步，刷新/筛选/停用隐藏 |

**关键交互**：
- 底部「演示角色」切换器：销售/实施仅看自己，销售总监/技术负责人看全部（Q4 权限演示）。
- 完整流程可走通：新建申请 → 销售总监节点1通过 → 团队负责人节点2通过 → 从人员池指派 → 执行人登记工时 → 推送 K 成功 → 任务完成；驳回分支亦通。

## 四、门户端原型

**文件**：`原型设计/客户与商机管理子系统-门户端.html`

**面向对象**：客户企业用户（如「华兴证券」）

**页面结构**：

| 页面 | 内容要点 |
|---|---|
| 登录 / 注册 | 登录页（含忘记密码、注册新账号入口） |
| 工作台 | 欢迎态 + 统计卡（进行中/已完成项目）+ 近期项目 + 快捷操作 |
| 我的项目 | 项目列表；项目详情（进度、里程碑、联系项目经理） |
| 报告中心 | 报告下载/提交审批 |
| 备案信息 | 依据《网络安全等级保护备案表（2025版）》6 张表 + 定级报告，分步填写提交 |
| 服务评价 | 客户对已完成服务的评价 |
| 账号安全 | 密码修改、账号信息 |

## 五、设计约定（两原型共用）

- **统一设计系统**：同一套 CSS Design Tokens（蓝/绿主色，卡片/标签/徽章/状态体系），视觉一致。
- **路由机制**：`navigate(page, opts)` → `render()` → 渲染侧边栏 + 页面；`store` 存放种子数据。
- **数据性质**：所有演示数据均为**虚构样例**，未连接真实后端，仅供评审/演示。
