# TS-005 工时登记与自动完成

## 1. 最新规则

当前源码核对：2026-10-22。新工时仅在 CRM 本地保存，登记后保持 `EXECUTING`，兼容字段 `push_status=SUCCESS` 不表示 PMS 已收到，也不生成新的 PMS outbox。执行人通过独立“结束进度”操作完成人工收口；旧 PMS 队列是独立兼容链。

另有“保存执行人全集替换”触发的自动完成分支，条件为：

```text
current_assignee_count > 0
AND every current assignee has at least one valid worklog for this task
```

有效工时为同任务、同当前执行人且未作废的已提交工时，不要求来自当前指派批次，不检查 PMS 回执。移出无工时人员或重新指派已有历史工时人员，可能在保存指派时立即完成。人工完成是独立规则，不要求工时。

## 2. 输入与换算

| 字段 | 规则 |
| --- | --- |
| person_id | 当前售前 Actor 使用基础平台 user_id；保留历史字段命名，不由浏览器指定他人，也不要求 PMS 映射 |
| work_start/work_end | 必填，end > start，不允许明显未来时间 |
| raw_unit | `小时/人天` |
| raw_value | `>0`，最多 2 位小数 |
| work_hours | 标准小时；小时原值，人天 × 配置系数，默认 8 |
| work_site_address | 必填；远程可填“远程”或实际地点 |
| work_content | 方案设计/技术交流/POC演示/技术答疑/其他 |
| remark | 可选，最多 1000 字 |

同一人员时间段不得与本任务已有工时重叠；实际数值/时间边界以服务端 `AddWorklog` 为准，不将未提供的管理配置页面写成已实现。

## 3. 数据表

`crm_presale_worklogs`：`worklog_no,request_id,person_id,department_snapshot,person_name_snapshot,work_start,work_end,raw_unit,raw_value,conversion_factor,work_hours,unit='小时',work_site_address,work_content,remark,push_status,push_attempts,idempotency_key,completed_task,created_at`。

不要沿用旧字段名 `raw_hours` 表示人天数；正式模型使用 `raw_value`，对外契约兼容旧名时由 DTO 映射。

## 4. 原子事务顺序

1. 锁定任务并校验 `EXECUTING`、当前执行人和 version。
2. 校验并换算工时，按当前指派保存姓名/部门快照，写 `push_status=SUCCESS` 的本地记录。
3. 同事务写业务证据；不调用自动完成、不新增 PMS outbox。
4. 人工完成另调用 `POST /presale/requests/{id}/complete`，核对权限、当前指派、执行角色、状态及版本，写 `MANUAL_COMPLETION` 和本地通知。
5. 全集替换后的 `completeIfReady` 在其独立指派事务内检查上述工时条件，满足时写 `ALL_CURRENT_ASSIGNEES_HAVE_WORKLOG`。

重复 Idempotency-Key 返回原 worklog，不重复完成或推送。

## 5. API 与前端

`POST /presale/requests/{id}/worklogs`、`GET /presale/requests/{id}/worklogs`。表单展示 `1 人天 = 8 小时`，服务端换算为标准小时。保存后刷新工时和任务；“结束进度”独立显示，不能提示登记即自动完成。

执行中允许多次登记；已完成只读历史，不再新增工时。

## 6. 验收

- 1 人天按当前配置准确落为 8 小时，并保留原始单位、数值和换算系数。
- 非当前执行人、非执行中任务、时间重叠、负数/零值均阻断。
- 单人或多人登记工时均不自动完成；达到100%进度也不完成。
- 人工完成允许零工时，仍校验权限、当前指派、角色、版本及执行状态。
- 工时事务失败不保存半条记录；指派替换自动完成在其同一事务内提交。
- 移出未参与的当前执行人后如已满足条件，任务在指派变更事务内自动完成。
- 新工时不依赖 PMS；历史队列真实投递、重试和死信另行验收，不能用本地 SUCCESS 代替外部回执。
- 幂等重放不生成第二笔工时或第二次完成日志。
