# TS-010 商机关联售前任务展示

## 1. 目标

在商机详情只读展示关联的售前任务，并提供“发起售前支持”入口。售前状态不自动推动商机阶段。

## 2. 展示字段

任务号、申请时间、状态、紧急度、场地、当前执行人、最新进度摘要、累计小时、期望结束、超时标志。联系人电话不在商机摘要卡展示。

## 3. API 与权限

`GET /opportunities/{id}/presale-requests?page=1&page_size=10`。先校验商机数据范围，再查 request；返回用户对每条任务的 `can_view_detail`。销售能访问自己的商机，但若售前数据范围更严，卡片只显示允许摘要。

发起入口调用 TS-001 context 接口，opportunity_id 预填只读。任务详情跳转仍由 TS-007 数据范围二次校验。

## 4. 前端

`OpportunityPresalePanel.vue`：有任务显示列表与“查看全部”，无任务显示空态；有 `presale.create` 时显示发起按钮。依赖查询失败只影响此面板，不阻断商机详情其他区域。

## 5. 验收

- 正确展示所有有权关联任务，状态和执行人与售前详情一致。
- 无任务空态和预填发起流程正确。
- 点击越权任务不能打开详情；API 无 IDOR。
- TS 完成、取消或改派后面板及时刷新。
- TS 状态变化不修改商机阶段。
