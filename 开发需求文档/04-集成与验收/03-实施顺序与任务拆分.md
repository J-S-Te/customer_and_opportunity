# 实施顺序与工程任务拆分

## Phase 0：接入与骨架

- 建立两个 Go 服务、统一 Vue 前端中的两个独立业务模块、两个 MySQL schema 和本地 Compose。
- 完成配置、日志、request_id、错误响应、migration、健康检查。
- CRM 完成 OIDC、本地会话、授权目录、租户/权限/数据范围中间件。
- Portal 完成基础平台 OIDC Authorization Code + PKCE、本地会话、`sub ↔ customer_id` 映射和授权目录，并关闭公开注册。
- 建立 CI：Go、Vue、migration、OpenAPI、镜像和依赖扫描。
