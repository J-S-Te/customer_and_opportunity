# PO-08 Portal OIDC 账号安全

## 1. 责任边界

PO-08 展示 Portal 会话和登录安全摘要。密码设置/修改/找回、登录失败锁定、MFA、身份凭据和全局账号禁用均由基础平台负责；Portal 不建立密码历史、密码复杂度或本地锁定逻辑。

## 2. Portal 提供的能力

- 显示当前统一身份账号的脱敏标识、上次 Portal 登录时间/IP/属地/设备；
- 显示当前 Portal 会话和其他 Portal 会话，允许撤销；
- 展示近期 Portal 登录成功、失败、sub 不匹配、权限失效等安全事件；
- 提供“前往统一身份账号安全中心”链接，用于改密、MFA 和账号恢复；链接必须来自可信配置/平台元数据，不由请求参数指定；
- 异常登录站内提示和事件确认。

## 3. 数据

- `portal_security_events(platform_user_id,customer_id,type,risk_level,ip_hash,location_snapshot,device_snapshot,occurred_at,acknowledged_at)`；
- 复用 CP-001 `portal_sessions` 和 `portal_auth_events`；
- 不创建 `portal_password_history`，不保存 password_hash、MFA secret 或基础平台认证失败明细。

## 4. API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/account/security` | 登录摘要、平台安全中心 URL、近期事件 |
| GET | `/api/v1/account/sessions` | 当前用户的 Portal 活跃会话 |
| DELETE | `/api/v1/account/sessions/{id}` | 撤销指定 Portal 会话 |
| POST | `/api/v1/account/security-events/{id}/ack` | 确认异常事件 |

若平台提供账号安全摘要 API，Portal 使用受控 scope 拉取最小数据；不可直读平台数据库。

## 5. 前端

`AccountSecurity.vue` 展示统一身份状态、登录信息、Portal 会话和安全事件。“修改密码/配置 MFA”按钮跳转基础平台安全中心，不在 Portal 弹出密码表单。

## 6. 验收标准

- Portal 页面和 API 无密码输入、改密、密码强度和本地锁定能力；
- 平台安全中心跳转只允许配置的可信 origin，并带安全 return URL；
- 用户只能查看/撤销自己的 Portal 会话；撤销立即生效；
- 安全事件不泄露 Token、Cookie、完整 IP 或其他账号信息；
- 基础平台角色回收、账号禁用或全局登出按约定时限反映到 Portal。
