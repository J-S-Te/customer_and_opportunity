# 文件校验策略（2026-09-07）

按用户要求移除 ClamAV 病毒扫描，保留统一文件网关及原有文件安全边界。当前策略优先于历史需求文档中的外部病毒扫描要求。

## 当前实现

- 删除共享 clamd 客户端、商机附件/客户导入 ClamAV 适配器及专属测试；删除 `CLAMAV_ENABLED`、`CLAMAV_NETWORK`、`CLAMAV_ADDRESS` 配置。
- 客户 XLSX 导入继续使用进程内静态校验和有界解析；商机附件继续使用静态文件校验器；Portal 备案材料继续使用标记 `static-v1` 的本地校验器。
- 保留格式/MIME、大小、路径、危险内容结构、摘要与对象一致性检查，以及租户隔离、权限、幂等、审计和受控下载。具体检查随文件类型而异。
- 历史数据库/API 的 `SCANNING`、`CLEAN`、`SCAN_FAILED` 状态与扫描凭证字段保持兼容；界面按“文件校验”展示。`CLEAN` 仅表示所配置校验器通过，不代表文件无病毒。
- 不执行病毒特征库检测，静态校验不能替代杀毒引擎，也不能保证发现所有恶意文件。未通过校验的文件仍不可下载。
- 不移除文件网关、对象存储或业务文件。Portal 报告水印/风险策略等未就绪依赖仍失败关闭，不因移除病毒扫描而开放。
