# 文件校验策略

当前调用链核验：2026-10-22；下方2026-09-07部署处置是历史记录，本轮未检查服务器或部署镜像。

按用户要求移除 ClamAV 病毒扫描，保留统一文件网关及原有文件安全边界。当前策略优先于历史需求文档中的外部病毒扫描要求。

## 当前实现

- 删除共享 clamd 客户端、商机附件/客户导入 ClamAV 适配器及专属测试；删除 `CLAMAV_ENABLED`、`CLAMAV_NETWORK`、`CLAMAV_ADDRESS` 配置。
- 客户 XLSX 导入继续使用进程内静态校验和有界解析；商机附件继续使用静态文件校验器；Portal 备案材料继续使用标记 `static-v1` 的本地校验器。
- 保留格式/MIME、大小、路径、危险内容结构、摘要与对象一致性检查，以及租户隔离、权限、幂等、审计和受控下载。具体检查随文件类型而异。
- 历史数据库/API 的 `SCANNING`、`CLEAN`、`SCAN_FAILED` 状态与扫描凭证字段保持兼容；界面按“文件校验”展示。`CLEAN` 仅表示所配置校验器通过，不代表文件无病毒。
- 不执行病毒特征库检测，静态校验不能替代杀毒引擎，也不能保证发现所有恶意文件。未通过校验的文件仍不可下载。
- 不移除文件网关、对象存储或业务文件。Portal 报告水印/风险策略等未就绪依赖仍失败关闭，不因移除病毒扫描而开放。

## 部署边界

生产服务器原本无 ClamAV 容器，CRM 运行配置没有 `CLAMAV_*`。2026-09-07 已移除服务器闲置的可选 ClamAV Compose 服务及环境模板配置，Compose 校验通过，无需重启业务容器。

服务器回滚备份：`/opt/basic-platform/backups/remove-clamav-20260907-eqBxYkS9`。本次源代码与前端文案修改仍在本地工作区，尚未发布生产镜像；不能将配置清理描述为代码已上线。

## 操作者流程与类型边界

| 用途 | 入口和权限 | 当前硬限制 | 成功判断 |
| --- | --- | --- | --- |
| 客户导入 | 客户管理→导入，customer.import | XLSX，10MiB，1000数据行；固定8列，预检30分钟 | 预检成功仍会写job/rows；提交后按成功/失败/跳过核对 |
| 商机附件 | 商机详情→附件；read/upload/download分权 | 20MiB，PDF、PNG/JPEG、DOCX、XLSX | 上传内容和最终化均确认，模块状态CLEAN且有下载权 |
| 备案材料 | 门户等保备案→材料；filing.update | 20MiB，PDF、PNG/JPEG | 对象不可变版本/摘要及CLEAN证据完整，再允许提交锁定 |

操作前刷新capability；按当前业务模板或允许格式选文件，等待完成核验后刷新资源，不以浏览器上传进度100%判断文件可下载。格式/大小/MIME/摘要不符应换符合规则的文件，503先由运维核对存储与校验装配，409刷新资源版本，拒绝/校验失败不得手工改CLEAN。

当前CRM可选S3兼容或本地存储，并有ATTACHMENT_FILE_GATEWAY_MODE=legacy/dual/required。非legacy客户导入先完成静态扫描、表头和业务预检，再在同一事务中保存job/rows、审计及加密源文件任务（迁移000120）。API进程内后台按部署租户和商业授权门禁执行HTTP网关V2上传并绑定SOURCE；稳定请求身份用于失败或响应丢失后的重放。预览完成或过期后，后台以原业务tuple幂等释放绑定，收到确认后清除CRM临时源文件密文，保留作业/行/审计；网关字节仍遵守网关保留策略，不删除长期保留文件。后台没有部署、凭据或网关依赖时任务保留待重试，预检成功不等于源文件已经上传。legacy模式不新增源文件任务。门户材料可装配HTTP网关或本地存储和LocalMaterialScanner。网关READY与模块CLEAN是不同边界，二者均只表示所配置静态策略通过。

Portal报告可按完整配置装配可信网关摄取、AES-GCM私有文件读取、审计风险与逐页水印；缺依赖/证据时失败关闭，半配置拒绝启动，不能由材料上传能力推断报告可下载。备案PDF为受配置的真实字段导出，不是官方完整模板。历史依据见[2026-10-13记录](../../.ai/modules/operation-docs-crm-20261013.md)，本轮见[文档同步报告](../../.ai/qa/docs-code-sync-20261022/agents/crm-contract-report.json)。
