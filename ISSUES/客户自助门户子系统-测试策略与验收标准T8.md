## 0. 范围说明（门户 V1.0 独立子系统）【本稿框架】

> **0.1 测试范围（对齐门户 PRD V1.0 §0.2）**
> 本 T8 覆盖门户子系统全部功能模块，对应 PRD 五类能力与前端 PO-01~PO-08：

| 模块 | 功能编号 | 前端页面 | 优先级 | 验收责任 |
|---|---|---|---|---|
| 门户访问控制 | CP-001 客户门户访问控制（含 PO-08 账号安全） | PO-01 / PO-08 | P0 | **本 T8** |
| 项目透明化 | CP-002 项目进度查询 | PO-02 / PO-03 / PO-07 | P0 | **本 T8** |
| 报告自助 | CP-003 电子报告申请与发放 | PO-04 | P0 | **本 T8** |
| 合规自助 | CUS-004 备案信息填写 | PO-05 | P1 | **本 T8** |
| 服务反馈 | CP-004 客户反馈与服务评价（a 评价 / b 反馈） | PO-06 | P1 | **本 T8** |

> **0.2 与本系统 T8 的分工边界**
> - **本 T8 负责**：上述全部门户功能的逐功能验收（§5）、门户数据质量（§6）、门户跨子系统接口（§7：上游开通门户/客户档案摘要、下游项目快照/报告 E/F）。
> - **本系统 T8 仅负责**：客户档案「生成注册链接（CM-004）」动作在客户与商机系统的**触发点**（其 §5.1 CM-004，含同步创建门户账号 M / 注册链接校验 N），不验收门户内部行为。门户**不支持自注册**，账号仅由上游同步创建。
> - 双方通过 §7 接口契约对齐，避免重复或遗漏。

> **0.3 接口契约范围（待确认事项 1 延伸）**
> API 契约 T4 **保留门户接口**；门户 T8 的 API 契约测试基于**完整 T4 的门户部分**（登录/项目/报告/备案/评价/反馈等），由本 T8 协同覆盖，**不按拆分重发"门户范围"版本**（与本系统 T8 §0.1 项 1 决策一致）。

> **0.4 安全合规重点（外部访问面）**
> 门户是等保三级的**高风险边界**，安全测试权重高于内部系统。重点控制：越权隔离（客户仅见自身）、登录爆破防护（5 次锁 15 分）、会话超时、**注册链接一次性 + 2h 有效期**（门户无自注册，账号由上游 CRM 在生成链接时同步创建）、默认口令 11223344 首登强制改密 + 口令复杂度参数、报告 AES-256 加密 + 水印 + 异常下载冻结、HTTPS 全站、审计不可篡改、敏感信息脱敏。等保三级测评于**上线前 1 月启动**（待确认事项 6）。

## 一、测试策略总览

### 1.1 测试金字塔（门户侧投入占比）

```
        /\        E2E（门户关键链路）          ~12%
       /  \       ------------------------------
      /----\       跨子系统集成（Mock 上下游）    ~18%
     /------\      API 契约测试（完整 T4 门户部分）~25%
    /--------\     集成测试（DB/缓存）            ~20%
   /----------\    单元测试                       ~25%
  /------------\
```

原则：**左移**（门户契约先行）、**自动化优先**（单测/接口 CI 回归）、**安全前置**（越权/加密类用例随功能开发同步）。

> 注（待确认事项 5 延伸）：门户 E2E **先覆盖关键链路自动化**（注册链接激活登录 → 强制改密 → 工作台 → 项目查询 → 报告申请 → 下载；备案填写提交；评价提交）；反馈（CP-004-b）因原型未实现（PRD §9 Q2）以**手工 + 接口**覆盖。

### 1.2 测试类型与覆盖目标

| 类型 | 目标覆盖 | 自动化 |
|---|---|---|
| 单元测试 | 加密/编号/邀请码校验/审批流转/异常下载冻结规则 | 必须 CI |
| 集成测试 | 服务 + DB（真实库，门户独立库） | 必须 CI |
| API 契约测试 | **完整 T4 门户部分**（schema/错误码/分页） | 必须 CI |
| 跨子系统集成 | §7 的 M/N/P2/D/E/F（Mock 上游/下游） | 必须 CI |
| 前端 E2E | **关键链路自动化，其余手工**（见 §1.1 注） | 关键路径 |
| 安全测试 | 等保 checklist + 渗透（OWASP Top 10），**门户全控制点** | 上线前 |
| 性能测试 | T2 指标 + **≥200 TPS 写基线（合成数据）** | 上线前 |
| 兼容性 | 浏览器矩阵（Chrome/Edge），移动端不测（PRD Non-goal 6） | 抽样 |

### 5.1 门户访问控制（CP-001，含 PO-08 账号安全）— P0 — 注册链接激活模型（V2.3）

| 验收项 | 验收标准（可量化） | 验证 | 优先级 |
|---|---|---|---|
| **无自注册（Non-goal）** | 门户**不支持任何自注册入口**（无"注册新账号"按钮/页面）；账号仅由上游 CRM 在生成注册链接时**同步创建**（T5 M） | F/A | P0 |

| 越权隔离 | 客户 A 不可访问客户 B 的项目/报告/备案（URL/API 越权拦截） | S | P0 |

| 登录信息卡 | 显示上次登录时间/IP/属地/设备（PO-08） | F | P0 |

## 七、跨子系统验收（门户视角，对齐 T5 并重建契约）

> 通道约定：MQ 异步流（至少一次 + 幂等键 + 死信）；Feign 同步流（超时 + 熔断 + 重试）。**门户不生成报告文件本身、不维护客户主数据、不管理项目执行**，仅做通道/快照消费。

| 编号 | 数据流 | 方向 | 验收标准 | 验证 |
|---|---|---|---|---|
